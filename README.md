## 🔧 Troubleshooting Common Issues

Even the best applications occasionally run into problems. Here are quick fixes for the most common issues you might encounter.

### Device Not Detected
Make sure your USB cable is working properly. Try a different cable or port. Ensure your phone is unlocked and the “Trust This Computer” popup has been accepted.

### Installation Stuck at 50%
This usually means the IPA file is corrupted. Download the IPA file again from a reliable source, delete the old one from your library, and try again.

### No Connection to Apple Device Wirelessly
Verify that both your computer and your phone are connected to the exact same Wi-Fi network. Disable any VPN services and restart the application.

### Application Crashes on Startup
Close any other sideloading tools running simultaneously. Update webipagui to the latest version. If the problem continues, restart your computer completely.

### IPA File Not Supported
Check that the file ends with `.ipa` and is not just renamed from another format. Also, ensure the app is compatible with your iOS version.
